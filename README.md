# apple-review-skill

`ios-build-review` проверяет готовую IPA или XCArchive перед App Review. Агент анализирует сборку локально, сверяет риски с действующими правилами Apple и сохраняет краткий Markdown-отчёт для разработчика.

Пакет использует открытый формат Agent Skills. Если агент умеет читать локальные файлы и вызывать инструменты, он также может выполнить проверку напрямую по `SKILL.md`. Для исполняемой части нужны доступ к сборке и локальная среда анализа. [Спецификация Agent Skills](https://agentskills.io/specification)

## Сообщение для установки

Скопируйте в своего агента:

> Установи ios-build-review из https://github.com/sou1t/apple-review-skill по README для агента, в котором ты работаешь. Проверь наличие reverse-engineer-anything и app-store-compliance и установи недостающие по указанным ссылкам. Если у тебя нет каталога скиллов, сохрани комплект локально для запуска по SKILL.md. В конце дай пример запроса с путём к моей сборке.

## Инструкция для агента

1. Клонируй репозиторий или распакуй полученный ZIP. Устанавливаемый пакет — папка `ios-build-review/` рядом с этим README. Копируй её целиком: методика и сборщик читаются по путям относительно `SKILL.md`.
2. Выбери каталог, из которого **текущий клиент** загружает скиллы. Для существующей установки Codex подходит `$CODEX_HOME/skills/` (по умолчанию `~/.codex/skills/`). В Claude Code для персональных скиллов используется `~/.claude/skills/`. В OpenCode для проекта подходит `.opencode/skills/`. Для другого клиента используй каталог из его документации. Готовый путь оканчивается на `ios-build-review/SKILL.md`. Если установленная копия совпадает, пропусти её; при отличиях согласуй обновление. [Claude Code](https://code.claude.com/docs/en/skills) · [OpenCode](https://opencode.ai/docs/skills/)
3. **Если клиент не регистрирует скиллы**, сохрани репозиторий в постоянной локальной папке, доступной агенту. Запомни абсолютный путь к `ios-build-review/SKILL.md` и передай его пользователю. Такую установку можно использовать в следующих чатах явным запросом по пути.
4. Установи недостающие связанные скиллы по инструкциям ниже. Для проверки основного пакета открой `references/analysis.md` относительно его каталога и выполни `python3 "<папка ios-build-review>/scripts/collect.py" --help`. При нативной установке проверь обнаружение скилла средствами клиента, при запуске по пути — чтение файлов. Если клиент перечитывает скиллы при старте, открой новую сессию. Если пакет по-прежнему отсутствует в списке, дай пользователю запрос для запуска по полному пути к установленному файлу.

## Запуск

Если клиент загрузил скилл, достаточно обычного запроса:

```text
Используй ios-build-review для проверки "/путь к сборкам/MyApp.ipa" и сохрани рекомендации в Markdown.
```

Для запуска по файлу подставьте путь, полученный при установке:

```text
Прочитай "/путь к пакету/ios-build-review/SKILL.md" и выполни его инструкции для "/путь к сборкам/MyApp.xcarchive".
```

В Codex также работает явный вызов `$ios-build-review`. Любой из способов принимает оба формата сборки.

Сборщик использует стандартную библиотеку Python 3. Полнота проверки зависит от локальных анализаторов. На macOS для проверки подписи и Mach-O используются в том числе `codesign`, `otool` и `nm`. Агент укажет существенные пропуски и способы их проверить. Для сверки с актуальными правилами нужен доступ к публичной документации Apple. Если клиент не видит локальные файлы и не умеет вызывать локальные инструменты, запустите проверку в среде с таким доступом.

## Связанные скиллы

Используй уже доступные копии. Для клиента без реестра скиллов сохрани недостающие пакеты рядом с основным, каждый в собственной папке. При запуске читай их `SKILL.md` по пути.

- **reverse-engineer-anything** разбирает локальные бинарники и ресурсы. Для поддерживаемого клиента выполни `npx rea-agents setup` в доверенной папке и выбери **текущий клиент**. Проверь доступность инструментов REA после подключения. Для клиента без интеграции возьми каталог скилла из репозитория REA и используй локальный REA CLI для поддерживаемых операций. [Установка и CLI](https://github.com/morluto/rea#quick-start) · [Каталог скилла](https://github.com/morluto/rea/tree/main/skills/reverse-engineer-anything)
- **app-store-compliance** помогает подобрать применимые правила Apple. Клонируй репозиторий и скопируй `agent-os/skill/SKILL.md` в `app-store-compliance/SKILL.md` внутри выбранного каталога скиллов. Рядом с этим файлом размести из корня исходного репозитория `docs/`, `data/`, `references/`, `templates/`, `scripts/`, `.citation-allowlist` и `VERSION`. Для статической проверки достаточно этих файлов. [Репозиторий](https://github.com/mjmirza/app-store-compliance) · [Файл скилла](https://github.com/mjmirza/app-store-compliance/blob/main/agent-os/skill/SKILL.md)
