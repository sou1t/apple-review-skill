# apple-review-skill

Скилл `$ios-build-review` для Codex проверяет готовую IPA или XCArchive перед App Review. Анализирует код и ресурсы локально, сверяет применимые правила с документацией Apple и сохраняет короткий Markdown-отчёт. В отчёт попадают технические замечания, риски App Review и лишнее содержимое релиза. Решение об отправке принимает разработчик.

## Установка через агента

Отправьте агенту Codex это сообщение:

> Установи персональный скилл ios-build-review из https://github.com/sou1t/apple-review-skill по инструкции в README. Проверь установленную копию.

Агенту, выполняющему установку:

1. Если передана ссылка на GitHub, клонируй репозиторий во временную папку. Если передан ZIP, распакуй его. Найди каталог `ios-build-review/` рядом с этим README.
2. Скопируй каталог целиком в `$CODEX_HOME/skills/` или, если переменная не задана, в `~/.codex/skills/`. Если скилл уже установлен, сравни файлы. При совпадении повторная установка не нужна. Если версии различаются, согласуй замену.
3. Сверь содержимое установленного каталога с `ios-build-review/`. Проверь запуск `python3 "<установленный каталог скилла>/scripts/collect.py" --help`.

Для локального сборщика нужен Python 3. На macOS скилл использует также инструменты Apple, включая `codesign`, `otool` и `nm`. Если для конкретной сборки нужны дополнительные анализаторы, агент предложит их во время проверки.

## Запуск

В новом чате Codex укажите путь к сборке:

```text
$ios-build-review Проверь "/путь к сборкам/MyApp.ipa"
```

```text
$ios-build-review Проверь "/путь к сборкам/MyApp.xcarchive"
```

Codex вернёт ссылку на отчёт. Каталог для сохранения можно указать в том же сообщении.

## Связанные скиллы

- `reverse-engineer-anything` — статический разбор локальных бинарников и ресурсов.
- `app-store-compliance` — подбор относящихся к находке правил Apple с последующей сверкой на официальном сайте.
